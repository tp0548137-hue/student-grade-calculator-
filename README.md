
# Student Grade Calculator

A simple Python project to calculate student
marks, percentage, and grade.

## Features
- Accepts student name
- Takes marks for 3 subjects
- Calculates total marks
- Calculates percentage
- Displays grade

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

   python main.py
